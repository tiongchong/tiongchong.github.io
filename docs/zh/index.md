# Benchkeeper

工程师、手作与系统构建者、丈夫与父亲｜马来西亚槟城

日常工作中，我习惯贴近底层与系统栈去思考与验证——从硬件、固件、嵌入式 Linux，到边缘 AI 验证与自动化测试流程；而在工作与家庭之间，我也在七口之家的生活节奏里持续学习、陪伴与同行。

走过二十余年的电子研发、FPGA/IP 应用、底层固件、软件验证，以及艺术装裱、文物修复与精密木工手作创业历程，我越来越看重一些朴素的原则：亲手验证所建之物，理解系统在真实约束下的表现，让每一份工作都经得起推敲。闲暇时，我喜欢折腾单片机、软件无线电（SDR）与自托管工具，也喜欢回到木工与手作的世界里静心打磨。

比技艺与履历更深层的，是我的基督徒信仰。这个网站不是为了展示光环，而是一本安静的随笔与记录本。这里主要收录三类内容：

- [信仰与灵修反思](faith/index.md) — 日常灵修读经的记录与操练结构的祷告。

- [阅读与书摘](reading/index.md) — 阅读历史、传记、品格与思想类书籍时的思考与整理（后续也将陆续加入新的阅读仓库）。

- [技术项目与手作](projects/index.md) — 工程实验、验证心得以及动手制作的真实记录。

这里没有现成的标准答案，只有一位仍在路上学习、建造并持守所信之人的真实轨迹。内容以三种语文呈现，盼望家人、朋友与路上的同行者，都能用自己最熟悉、最自在的语言读到这些分享。
